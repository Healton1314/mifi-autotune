让手机自己跑（一次性安装）

现在这个页面靠电脑上的服务在跑，电脑关了就没了。 想彻底摆脱电脑：把代码装到手机里，之后手机连着随身WiFi 就能自己体检、自己优化。
手机装 Termux（F-Droid 版更稳），打开后依次粘贴这几行：
pkg install -y python
python -c "import urllib.request as u;open('p.zip','wb').write(u.urlopen('__PKG_URL__').read())"
python -m zipfile -e p.zip ~
bash ~/mifi-autotune/phone/install.sh
装完后在 Termux 里输入 mifi 就能启动，不再需要这台电脑。
